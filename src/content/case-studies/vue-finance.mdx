      <h2 id="vf-tokens" class="text-balance text-3xl md:text-4xl font-semibold tracking-tight text-neutral-900 dark:text-neutral-100">One token set, three money colors</h2>
    </div>
    <div class="mb-8 grid gap-6 lg:grid-cols-2 lg:gap-12">
      <div class="max-w-[60ch] space-y-4">
        <p>The 2026 style is white and blue, with flat cards, hairline borders, and light type. The style is inspired by Ubiquiti UniFi and iOS 7 to 10. A translucent top bar stays in view while the page scrolls.</p>
        <p>Colors, radii, and fonts live in CSS variables in one file. The dark theme changes the values, not the components. The chart reads the same variables, so the donut follows the theme without extra code.</p>
      </div>
      <div class="max-w-[60ch] space-y-4">
        <p>Income is green, expenses are red, and investments are purple. Investments use purple so they never look like the brand blue. Plus Jakarta Sans is bundled with the app. Apple system fonts are the fallback. Money uses tabular numerals so amounts line up in columns.</p>
        <p>Color is never the only signal. Every category has a label. Income rows carry a plus sign and expense rows carry a minus sign. Investment rows have no sign yet.</p>
      </div>
    </div>
    <div class="mb-8 border-l-2 border-neutral-300 pl-5 dark:border-neutral-700">
      <p class="max-w-[68ch]">I computed contrast ratios from the token values. In light mode, body text on the page background is about 15 to 1. Muted text is 5.3 to 1. White text on the brand blue is 5.6 to 1. In dark mode, muted text on a card is 7.7 to 1. Every pair I checked is above 4.5 to 1. These numbers come from the tokens, not from measured pixels. I did not test with a screen reader.</p>

    <div class="mb-8 max-w-[28ch]">
      <h2 id="vf-contract" class="text-balance text-3xl md:text-4xl font-semibold tracking-tight text-neutral-900 dark:text-neutral-100">The hard part was the contract between layers</h2>
    </div>
    <div class="max-w-[68ch] space-y-5">
      <p>The 2024 goal was a simple tracker with Vue, GraphQL, and Tailwind. The scope grew to include API design, Express, MongoDB, Passport sessions, and password hashing. I worked on both sides, so I could follow a form entry into the database and back into the dashboard.</p>
      <p>The 2024 report names schema, type-definition, and mutation mismatches as the main debugging cost. A small mismatch showed up as null or undefined in the interface. I traced requests through the layers and wrote TypeScript types by hand for the untyped JavaScript responses. That worked for a small project. It also duplicates the contract, which is a maintenance cost.</p>
      <p>Creating or deleting a transaction asks the server for fresh table data and fresh category totals. The table and the chart update without a manual reload.</p>
      <p>Sign-up and login use Passport sessions. Passwords are hashed with bcrypt before they reach the database. The session lives in an HTTP-only cookie.</p>
      <p>For the 2026 pass I added a Docker Compose file for MongoDB and the API, and a seed script. The script creates one demo user and 45 sample transactions. The amounts are generated sample data.</p>
